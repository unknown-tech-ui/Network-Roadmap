# Web & Network Security — 7 Day Roadmap

A beginner-friendly, 7-day introduction to how the web works and how it can break — covering HTTP, common web vulnerabilities (XSS, SQLi, IDOR), cryptography basics, TLS/PKI, DNS & networking and a guided recon-to-flag capstone.

No prior security experience required. Designed for guided, in-person or cohort-based delivery, with self-checkable exercises throughout.

## Who this is for

- Complete beginners to cybersecurity who are comfortable using a computer and a terminal
- Anyone who wants a self-paced path through the same material (most days are self-checkable)

## Quick start

1. Read [`SCOPE.md`](./SCOPE.md) first.
2. Follow [`SETUP.md`](./SETUP.md) to install what you need before Day 1.
3. Work through [`ROADMAP.md`](./ROADMAP.md) day by day.
4. Use [`LINKS.md`](./LINKS.md) any time you want to go deeper on a topic.

## By the end of Day 7, you'll be able to

- Explain how a webpage loads and read basic requests/cookies in DevTools
- Recognize XSS, SQL injection, and broken access control when you see an example of each
- Explain the difference between encryption and hashing, and why hashed+salted passwords matter
- Explain what a certificate and the padlock icon actually guarantee, and spot an invalid certificate
- Explain what DNS, firewalls, VPNs, and proxies each do
- Run a basic Nmap scan and look up a domain's certificate history
- Follow a guided path connecting an app vulnerability to a network-level flag
