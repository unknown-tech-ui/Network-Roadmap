# Internet & Networking Roadmap — 7 Day Bootcamp

A beginner-friendly, 7-day cybersecurity & networking bootcamp — covering how the web works, common web vulnerabilities (XSS, SQLi, IDOR), cryptography basics, network forensics with Wireshark, DNS & core networking concepts, recon/enumeration with Nmap, and a guided recon-to-flag capstone.

No prior security experience required. Designed for guided, cohort-based delivery (e.g. a fresher/bootcamp week), with self-checkable exercises and mini-challenges throughout.

## Who this is for

- Complete beginners to cybersecurity and networking who are comfortable using a computer and a terminal
- Anyone who wants a self-paced path through the same material (most days are self-checkable)

## Quick start

1. Read [`SCOPE.md`](./SCOPE.md) first.
2. Follow [`SETUP.md`](./SETUP.md) to install what you need before Day 1.
3. Work through [`Internet_Networking_Roadmap.md`](./Internet_Networking_Roadmap.md) day by day.
4. Use [`LINKS.md`](./LINKS.md) any time you want to go deeper on a topic.

## By the end of Day 7, you'll be able to

- Explain how a webpage loads and read basic requests/cookies in DevTools
- Recognize XSS, SQL injection, and broken access control when you see an example of each
- Explain the difference between encoding, hashing, and encryption — and break a weak (single-byte XOR) cipher
- Open a `.pcap` in Wireshark and pull a cleartext credential out of captured traffic
- Explain what DNS, TCP/UDP, firewalls, VPNs, and proxies each do
- Run a basic Nmap scan and look up a domain's certificate history
- Follow a guided path connecting an app vulnerability to a network-level flag, understanding how each day's topic linked to the next
